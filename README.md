# Huaihai Lyu Personal Homepage

Static academic personal homepage for GitHub Pages.

## Local Preview

Open `index.html` directly in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages Deployment

1. Create a GitHub repository, for example `huaihai-lyu.github.io`.
2. Push this folder to the repository's `main` branch.
3. In GitHub, open `Settings -> Pages`.
4. Set the source to `Deploy from a branch`.
5. Select `main` and `/root`.
6. Save and wait for GitHub Pages to publish the site.

If the repository is named `<username>.github.io`, the site will be available at:

```text
https://<username>.github.io/
```

For a normal project repository, the site will be available at:

```text
https://<username>.github.io/<repository-name>/
```
